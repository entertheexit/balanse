# Balanse

Balanse is a local-first double-entry ledger app that imports Thai bank and credit card statements.

- [Product and data overview](docs/README.md)
- [Public statement recipes](https://github.com/entertheexit/balanse-recipes)
- [Product feedback and support](https://github.com/entertheexit/balanse/issues)

This repository hosts public project documentation. The application source and cloud service source are maintained in separate private repositories. Recipe contributions belong in the public recipes repository.
