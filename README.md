# Balanse

Balanse is a local-first double-entry ledger app that imports Thai bank and credit card statements.

- [Product and data overview](docs/README.md)
- [Bank statement template repositories](https://github.com/orgs/balanse-finance/repositories)
- [Product feedback and support](https://github.com/entertheexit/balanse/issues)

This repository hosts public project documentation. The application source and cloud service source are maintained in separate private repositories. Each bank maintains its own template repository. Submit template improvements and synthetic examples to the corresponding bank.
